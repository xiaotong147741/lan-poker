# 局域网多人德州扑克（C++ / Qt）

一个基于 C++ 与 Qt5 的局域网多人德州扑克游戏：房主在自己电脑上开房，朋友通过局域网 IP 加入，同屏对战。

> **平台支持**：目前仅支持 **Linux**（已在 Ubuntu + Qt 5.15 验证）。Windows 暂不可用——网络层基于 POSIX socket，需适配 Winsock 后才能编译，详见文末「已知限制」。

## 平台支持

| 平台 | 状态 |
|---|---|
| Linux（Ubuntu / Debian 等） | ✅ 已支持并验证 |
| Windows | ❌ 暂不支持（网络层依赖 POSIX socket，需移植 Winsock） |
| macOS | ⚠️ 理论可编译，未验证 |

## 下载即玩（推荐）

不想编译的话，直接下载打包好的 Linux 版本：

1. 打开本仓库的 **[Releases](../../releases/latest)** 页面，下载 `poker-linux-x86_64.tar.gz`；
2. 解压后执行里面的 `run.sh`（双击或在终端运行）；
3. 要求：x86_64 Linux 桌面环境（Ubuntu 20.04+ 等），无需另装 Qt。

> 所有玩家（包括房主）用的是同一份程序，无需任何开发环境。

## 功能

- **三页界面流程**：连接页（创建 / 加入房间）→ 等待室（实时名单、准备、房主开始）→ 牌桌
- **自定义房间**：端口、初始筹码、大盲注（小盲自动为一半）、最大人数（2~9）、局数
- **等待室实时同步**：昵称、房主标记、准备状态，任何人进出或准备状态变化都会立即广播刷新
- **完整牌局规则**：盲注与按钮位轮转、四条街、弃牌 / 过牌 / 跟注 / 加注、最小加注约束、全下、边池分层结算、未跟注筹码退回、跨手筹码保留与出局判定
- **牌型判定**：从 7 张牌中枚举组合选出最优 5 张，覆盖高牌到同花顺
- **对局视觉反馈**：轮到的玩家座位绿色高亮，摊牌时主池赢家金色高亮，显示各家牌型
- **服务器权威架构**：客户端不本地结算，筹码、底池、行动顺序全部由服务器广播

## 如何游玩（给非技术朋友）

> 前提：从上方「下载即玩」拿到程序，解压后运行 `run.sh`。所有玩家（含房主）都用同一份程序，无需编译、无需安装 Qt。

### 房主（开房的人）

1. 打开游戏程序，在「创建房间」中填写：昵称、端口（默认 8888 即可）、初始筹码、大盲注、最大人数、局数，点「创建房间」；
2. 界面上会显示你的**本机局域网 IP**（例如 `10.103.81.225`），把这个 IP 告诉朋友；
3. 朋友陆续进入等待室后，请他们点「准备」；
4. 全员准备好后，你界面的「开始游戏」按钮会变亮，点击即开局。

### 加入者（朋友）

1. 打开游戏程序，在「加入房间」中填写：昵称、**房主 IP**、端口（默认 8888）；
2. 点「加入房间」，成功后进入等待室；
3. 点「准备」，等房主开始游戏。

### 连不上怎么办

- 确认双方连的是**同一个 Wi-Fi / 局域网**；
- 房主机器的防火墙要放行游戏端口（Linux：`sudo ufw allow 8888/tcp`）；
- 如果对方 `ping 房主IP` 不通，可能是校园网/公共 Wi-Fi 的 **AP 隔离**，换手机热点再试；
- 端口被占用时，换一个端口（如 9000）重建房间，朋友也用同一端口加入。

## 项目结构

```
.
├── newgui/                  # Qt 客户端（qmake 工程）
│   ├── connectpage.*        #   连接页：创建/加入房间，显示本机局域网 IP
│   ├── waitpage.*           #   等待室：玩家名单、准备、开始
│   ├── mainwindow.*         #   牌桌界面 + 网络状态机（QSocketNotifier 接入事件循环）
│   ├── mainwindow.ui        #   牌桌界面布局与样式表
│   └── newgui.pro           #   客户端工程文件
├── net_host.cpp             # 服务器：runServer() 双入口（控制台 / 客户端线程内）
├── net.cpp / net.h          # socket 封装：监听、连接、收发（整数与字符串）
├── utils.cpp                # 核心逻辑：洗牌、发牌、牌型判定、边池结算
└── card.h                   # 数据结构定义
```

**架构要点**：服务器逻辑封装为 `runServer(port, startChips, bigBlind, maxPlayers, handNum)`。

- 控制台入口：编译 `net_host.cpp` 得到独立服务器程序，便于开发调试；
- 客户端入口：`#define EMBEDDED_SERVER` 后，客户端的"创建房间"在后台线程中调用同一份 `runServer`，随后自己连接 `127.0.0.1`——房主无需额外部署服务器。

## 网络协议

基于 TCP 的自定义二进制协议，消息以 int 指令码（`step`）开头，接收方按顺序读取定长字段；字符串采用"长度前缀 + 字节"编码。

### 服务器 → 客户端

| step | 含义 | 载荷 |
|---|---|---|
| 10 | 入座开局 | 座位号、总人数、全员昵称 |
| 11 | 发底牌 | 2 张牌（花色、点数） |
| 12 | 发公牌 | 本街张数、各牌（花色、点数） |
| 14 | 盲注信息 | 小盲位、大盲位、大盲额、各人筹码、底池、当前注额 |
| 1 | 轮到你 | 底池、当前注额、需跟注额、我的筹码、我的本街投入、最小加注 |
| 2 | 他人行动广播 | 座位、动作、注额、剩余筹码、底池、当前注额、最小加注、本街投入 |
| 15 | 当前行动者 | 座位号（用于高亮） |
| 13 | 摊牌结算 | 是否亮牌、各家底牌、各人筹码、是否继续、主池赢家数组 |
| 30 | 你的房间序号 | 0 = 房主 |
| 31 | 等待室名单 | 人数、每人（昵称、准备状态）、房主序号 |

### 客户端 → 服务器

| 指令 | 含义 |
|---|---|
| 22 + 字符串 | 连接后自报昵称 |
| 21 | 切换准备状态 |
| 20 | 房主请求开始游戏 |
| 1 / 2 / 3 / 4 | 弃牌 / 过牌 / 跟注 / 加注（加注后附目标注额） |

## 编译与运行

### 客户端（Qt 5.15+，qmake）

```bash
cd newgui
qmake newgui.pro && make
```

或用 Qt Creator 打开 `newgui/newgui.pro` 构建（发布时建议 Release）。

### 独立服务器（可选，开发调试用）

```bash
g++ -std=c++11 -o host net_host.cpp net.cpp utils.cpp
./host    # 默认端口 8888、筹码 1000、大盲 10、最多 9 人、3 局
```

### 运行

具体操作见上方「如何游玩」一节。房主机器需放行对应 TCP 端口（Linux：`sudo ufw allow 8888/tcp`）。

## 已知限制

- 牌局中途掉线与中途加入（排队）尚未实现：**请勿在牌局进行中关闭客户端窗口**；
- 房间按创建时设定的局数进行，结束后需重新创建；
- 网络层基于 POSIX socket，尚未移植 Windows（如需 Windows 版需适配 Winsock）；
- 依赖局域网连通性，部分校园网/公共 Wi-Fi 的 AP 隔离会导致无法互连。
